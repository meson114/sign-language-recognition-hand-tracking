# 套件與環境

請使用原本能運作的 Python 解譯器與套件環境。本專案沒有自動下載或安裝環境的程式。

| 模組 | 使用的套件／服務 |
|---|---|
| 影片擷取 | OpenCV (`cv2`)、MediaPipe (`mp.solutions.hands`)、NumPy |
| 訓練 | pandas、NumPy、scikit-learn、TensorFlow/Keras、Matplotlib、joblib |
| CSV 分類測試 | pandas、NumPy、scikit-learn、TensorFlow/Keras、joblib |
| 攝影機 | OpenCV、MediaPipe、NumPy、TensorFlow/Keras、joblib；選用 pyttsx3 |
| Leap | 所附現代 leap API、原有 leapc_cffi／CFFI、Ultraleap SDK／追蹤服務及裝置 |
| Unity | Unity 執行環境、Newtonsoft Json 套件 |

`socket`、`json`、`threading`、`pathlib`、`csv` 為 Python 標準函式庫。

原專題未保存完整的套件版本鎖定檔，因此無法保證任意新版環境都能載入舊 `.h5`。若發生 `mediapipe.solutions`、Keras 載入或 DLL 錯誤，先確認是否使用原本能運作的環境。本次沒有遷移至新版 API。

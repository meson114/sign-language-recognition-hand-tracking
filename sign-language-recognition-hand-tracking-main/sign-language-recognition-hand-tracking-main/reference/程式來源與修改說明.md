# 程式來源與修改說明

本儲存庫保留整理後的主流程。原始實驗程式、逐檔差異、原始備份、舊模型與舊報表僅保留在專題擁有者本機，未公開上傳。

| 整理版 | 原專題來源 | 主要調整 |
|---|---|---|
| `scripts/01_extract_keypoints.py` | `new extract.py` | 保留手腕中心化與 CSV 格式；相對路徑、逐影片重設追蹤器、統一單手 |
| `scripts/02_train.py` | `train.py` | `build_model` 與原版一致；修正先按影片分組、只用訓練資料擬合 scaler，再切視窗 |
| `scripts/03_evaluate_csv.py` | `csv validation.py`、`validation.py` | 對齊中心化模型，載入訓練 scaler、平均視窗機率、預設使用保留測試影片 |
| `scripts/04_predict_videos.py` | `validation.py` | 統一模型配對與資料規則，逐影片重設追蹤器 |
| `scripts/05_webcam.py` | `untitled9.py` | 保留信心門檻與穩定判斷，統一單手與模型配對，語音設為選用 |
| `scripts/project_config.py` | 原程式重複的路徑、特徵、切窗與載入邏輯 | 共用輔助檔，補上 CSV 與模型尺寸檢查，不包含新模型 |
| `leap_unity/python/gesture_sender.py` | `gesture_sender.py` | 保留 Listener、掌心座標、JSON 與握拳邏輯；補上連線管理及左右手標籤 |
| `leap_unity/unity/PythonToUnityReceiver.cs` | `PythonToUnityReceiver.cs` 的有效類別 | 保留 TCP／JSON 與物件移動；補上斷線處理、最新座標與左右手分流 |

`reference/action_labels.json` 取自原 `new extract.py` 的 64 類對照表。`models/current/` 初始模型與 scaler 依原 `train.py` 的輸出名稱選取，並非整理時重新訓練。

`leap_unity/vendor/` 是主流程引用的現代 Leap API／繫結原始碼，為執行與環境維護所需，因此保留；它不是原專題各種測試程式的備份。
